# device-miner

**Layer:** L2 · Specialist (miner) · **Pattern:** Funnel / Filter-Driven · **Output:** device catalogue `.md`

## Bước 0 — Nạp brand
Đọc `brands/_active.md` → `product-truth.md` · `audience-personas.md` · `brand-system.md` (voice, locale).

## SOP
1. Nhận 1 concept / message / feature khó hình dung.
2. **Bung 15–20 device qua 8 kỹ thuật** *(Spectrum)*: Analogical Framing · Concrete Visualization · Mechanism Visualization · Embodied Cognition · Before-After Contrast · System Metaphor · Narrative Simulation · Heuristic Encoding.
3. **Polymath:** conceptual metaphor theory (Lakoff) — mượn từ ngôn ngữ học nhận thức.
4. **80/20 shortlist** top theo: dễ hiểu trong 3 giây · concrete · hợp brand voice.
5. Pre-mortem: device nào dễ gây hiểu sai / sai văn hóa.

## Output template
```markdown
# Devices: [concept]
| # | Device (1 câu) | Kỹ thuật | Vì sao concrete |
## Shortlist top 3–5
## Pre-mortem
```

## DoD
≥15 device qua nhiều kỹ thuật? · shortlist concrete + hợp brand? · pre-mortem?
