# demo-scripter

**Layer:** L2 · Specialist (transformer) · **Pattern:** Reverse / Target-Driven · **Output:** demo scenes `.md`

## Bước 0 — Nạp brand
Đọc `brands/_active.md` → `product-truth.md` (feature + proof) · `brand-system.md` (locale).

## SOP
1. **Trích invisible promise:** điều người dùng KHÔNG tự thấy nếu chỉ đọc spec.
2. **Bung 5–7 moment of truth** qua 5 heuristic *(Spectrum)*: Surprise Contrast · Speed · Personalization · Adaptive · Emotional.
3. **Chọn 3 moment mạnh nhất** *(80/20)*.
4. **Phát triển 3 cảnh DSTR:** Setup · Stake · Trigger · Reveal.
5. **Render 3 format:** Live demo (sales) · Video script (TikTok/Reels) · Static scene (landing/slide).
6. Pre-mortem: cảnh nào khó dựng / không thật.

## Output template
```markdown
# Demo scenes: [feature]
Invisible promise: …
## 3 cảnh DSTR
### Cảnh [n]: Setup · Stake · Trigger · Reveal
- Live demo: … · Video: … · Static: …
## Pre-mortem
```
